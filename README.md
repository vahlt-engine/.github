# VAHLT organization profile

Public profile and approved visual assets for [VAHLT](https://github.com/vahlt-engine), an Encapsa business developing AI security infrastructure.

The organization overview is maintained in [`profile/README.md`](profile/README.md). Its two flagship research programs are **Prepared Prompts** and **Agent Trust Exchange**.

Both programs are beginning with controlled prototypes and scoped private-beta design partnerships. This repository contains profile content and brand assets; it does not contain or announce a released SDK or production runtime.

Pilot inquiries: [Discuss a VAHLT pilot with Encapsa](https://encapsa.ai/contact).

The VAHLT name, wordmark, symbol, and diagrams are brand materials. This repository does not grant a software license for future VAHLT products. Any software released separately will state its own scope, maturity, and license.
